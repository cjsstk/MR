# MR 게임 기획서

---

## 1. 게임 개요

| 항목 | 내용 |
|------|------|
| 장르 | 3인칭 액션 RPG |
| 플랫폼 | PC |
| 플레이어 수 | 싱글플레이 |
| 레퍼런스 | 몬스터헌터 라이즈, 몬스터헌터 월드 |
| 핵심 경험 | 거대 몬스터를 사냥하고 그 소재로 더 강한 장비를 만드는 성장 루프 |

---

## 2. 핵심 루프

```
마을 (준비)
  ↓
퀘스트 수락 → 무기·방어구 정비 → 아이템 세팅
  ↓
필드 (사냥)
  ↓
탐색 → 발자국/흔적 추적 → 몬스터 조우 → 전투
  ↓
토벌 or 포획 → 소재 수집
  ↓
귀환 → 소재로 제작/강화 → 퀘스트 랭크 상승
  ↓
마을 (다음 루프)
```

## 3. 월드 구조

### 3-1. 마을 (Village)

중심 허브 공간. 모든 준비와 사교 활동이 이루어진다.

| 구역 | 기능 |
|------|------|
| 퀘스트 게시판 | 퀘스트 수락·조회 |
| 대장간 | 무기·방어구 제작·강화 |
| 아이템 상점 | 소모품 구매 |
| 창고 | 소재·아이템 보관 |
| 식당 | 버프 식사 (스태미나 상한 증가, 공격력 업 등) |
| 캐릭터 커스터마이즈 | 외형, 칭호 설정 |

### 3-2. 필드 (Field / Hunting Ground)

퀘스트마다 지정된 맵으로 진입. 오픈 구조 + 구역 분리 혼합.

| 필드 | 환경 | 주요 몬스터 예시 |
|------|------|----------------|
| 야생 삼림 | 숲·습지 혼합 | 중형 육식 몬스터 |
| 화산 지대 | 용암·동굴 | 화속성 드래곤류 |
| 설원 | 눈보라·빙하 | 빙속성 수인형 몬스터 |
| 사막 폐허 | 모래 폭풍·유적 | 독속성 갑각류 |
| 심해 동굴 | 수중·어둠 | 발광 어룡류 |

각 필드는 **구역(Zone) 10~15개**로 구성. 몬스터는 체력에 따라 구역 이동.

## 4. 플레이어 캐릭터

### 4-1. 기본 스탯

| 스탯 | 설명 |
|------|------|
| 체력 (Health) | 0이 되면 기절/실패 |
| 스태미나 (Stamina) | 회피·스프린트·특정 액션 소모 |
| 방어력 (DefensePower) | 피해 감산 |
| 공격력 (AttackPower) | 무기 데미지 배율 |

### 4-2. 이동 시스템

| 액션 | 조건 | 스태미나 |
|------|------|---------|
| 걷기 | 기본 | 소모 없음 |
| 달리기 (Sprint) | Shift 유지 | 지속 소모 |
| 회피 (Dodge) | 방향 + 회피키 | 1회 소모 |
| 구르기 (Roll) | 전투 중 회피 | 1회 소모 |
| 슬라이딩 | 경사면 달리기 | 소모 없음 |

### 4-3. 록온 / 조준 모드 (Targeting Mode)

근접 무기의 **록온(Lock-on)** 또는 활의 **조준(Aim)** 중에는 이동·회피 방식이 전면 전환된다.

| 항목 | 일반 모드 | 록온/조준 모드 |
|------|----------|--------------|
| 캐릭터 회전 | 이동 방향을 바라봄 (`OrientToMovement`) | 카메라/타겟 방향 고정 (`UseControllerYaw`) |
| 이동 애니메이션 | 1D BlendSpace (속도) | 2D BlendSpace (X: 좌우 stafe, Y: 전후) |
| 회피 | 단일 전방 구르기 몽타주 | 입력 방향 기준 4방향 회피 몽타주 (전·후·좌·우) |
| 스프린트 | 가능 | 불가 (록온 해제 후 가능) |

**2D BlendSpace 축 정의 (록온 모드 전용)**
- X축 `-1 ~ 1`: 좌 stafe → 우 stafe
- Y축 `-1 ~ 1`: 후진 → 전진
- 블렌딩 포인트: 8방향 + 정지(0, 0)

**4방향 회피 몽타주**
- `Dodge_Forward` — 전방 구르기
- `Dodge_Backward` — 후방 구르기
- `Dodge_Left` — 좌측 사이드스텝
- `Dodge_Right` — 우측 사이드스텝
- 입력 벡터를 캐릭터 로컬 좌표로 변환 후 가장 가까운 방향 몽타주 선택

### 4-4. 상태 태그 (GAS)

```
Character.State.Moving
Character.State.Sprinting
Character.State.Dodging
Character.State.Attacking
Character.State.Guarding
Character.State.Staggered
Character.State.KnockedDown
Character.State.Invincible   ← 회피 무적 프레임
Character.State.Dead
State.Stamina.RegenBlocked
```

## 5. 전투 시스템

### 5-1. 기본 전투 원칙

- **부위 파괴**: 몬스터 머리·날개·꼬리 등 부위별 독립 HP. 파괴 시 추가 소재 드롭 + 행동 패턴 변화
- **속성 상성**: 각 몬스터는 약점 속성 보유. 약점 공격 시 데미지 배율 증가
- **상태이상**: 독, 수면, 기절, 마비, 화염, 빙결 등. 누적 임계값 도달 시 발동
- **부위 피격 판정**: 히트박스를 부위별로 세분화. 동일 피격 부위에 데미지 집중 시 부위 파괴 촉진

### 5-2. 콤보 시스템

무기마다 고유 콤보 트리. 버튼 타이밍·방향 입력으로 분기.

```
기본 공격 (LMB)
├── 2타 → 3타 → 피니셔
├── 차지 공격 (LMB 홀드)
└── 강공격 (RMB)
    ├── 스매시
    └── 차지 스매시

특수 액션 (E)         ← 무기마다 고유
가드 (RMB 홀드)       ← 방패계 무기만
```

### 5-3. 히트스톱 & 카메라 연출

- 강공격 명중 시 히트스톱 (0.05~0.1초 슬로우)
- 부위 파괴 순간 카메라 줌인 + 파티클 강조
- 몬스터 쓰러짐(다운) 시 마운트 공격 진입 가능

### 5-4. 가드 시스템 (방패계 무기)

| 상황 | 결과 |
|------|------|
| 완벽 가드 (타이밍 일치) | 스태미나 소모 없음 + 반격 창 |
| 일반 가드 | 스태미나 소모, 피해 감산 |
| 가드 불가 공격 | 관통, 전체 피해 |

## 6. 무기 시스템

핵심 차별화 요소. **무기 타입마다 독립된 애니메이션 블루프린트와 콤보 로직** 보유.

### 6-1. 무기 타입 목록

| # | 무기 | 특성 | 조작 난이도 |
|---|------|------|------------|
| 1 | 한손검 (One-Handed Sword) | 빠른 공격, 방패 가드 가능 | ★☆☆ |
| 2 | 대검 (Great Sword) | 강력한 차지 공격, 느린 속도 | ★★☆ |
| 3 | 쌍검 (Dual Blades) | 연속 난타, 높은 기동성 | ★★☆ |
| 4 | 창 (Lance) | 돌진+가드, 방어 특화 | ★★★ |
| 5 | 해머 (Hammer) | 기절 특화, 차지 연계 | ★★☆ |
| 6 | 활 (Bow) | 원거리, 코팅 시스템 | ★★★ |

> 초기 구현: **한손검** 우선 완성 → 순차 추가

### 6-2. 무기별 구현 구조

```
EMRWeaponType (Enum)
  → ABP 선택 (AnimBlueprint)
  → Combo Data (DataTable Row)
  → Ability Set (GAS AbilitySet)
  → Montage Set (공격·가드·특수)
```

### 6-3. 무기 강화 트리

```
기본 무기
├── 강화 I → II → III (소재 + 제니)
└── 파생 A (속성 추가)
    └── 파생 A-II
파생 B (특수 효과)
```

각 무기는 **공격력, 속성 데미지, 상태이상 수치, 특성(스킬 슬롯)** 보유.

## 7. 방어구 시스템

### 7-1. 방어구 부위

머리 / 몸통 / 팔 / 허리 / 다리 (5부위)

### 7-2. 방어구 스킬

각 방어구 파츠에 **스킬 슬롯** 보유. 동일 스킬을 여러 파츠에서 누적하면 발동.

| 스킬 예시 | 효과 |
|---------|------|
| 공격력 강화 Lv1~3 | 공격력 +5/10/20 |
| 체력 강화 Lv1~3 | 최대 체력 +30/60/100 |
| 스태미나 급속회복 | 스태미나 회복 속도 2배 |
| 약점 특효 | 약점 부위 피격 시 추가 배율 |
| 가드 강화 | 가드 불가 공격 일부 가드 가능 |
| 독 내성 | 독 상태이상 면역 |

### 7-3. 장식주 (Jewel)

방어구의 보석 슬롯에 삽입. 스킬 레벨 보완 수단.

## 8. 몬스터 시스템

### 8-1. 몬스터 분류

| 분류 | 예시 특성 |
|------|----------|
| 소형 몬스터 | 무리 행동, 낮은 체력, 수동적 |
| 중형 몬스터 | 단독 행동, 부위 파괴 2~3곳 |
| 대형 몬스터 (보스) | 부위 파괴 5곳 이상, 페이즈 변화 |

### 8-2. 몬스터 AI 구조

```
Idle → Patrol
          ↓ (플레이어 감지)
       Alert → Combat
                 ├── 근거리 패턴
                 ├── 원거리 패턴
                 ├── 분노(Enrage) 패턴  ← HP 30% 이하
                 └── Flee (도망)        ← HP 10% 이하, 포획 가능 구간
```

### 8-3. 몬스터 데이터 (DataTable)

```cpp
FMonsterRow
{
  MonsterType,    // 몬스터 ID
  BaseHealth,     // 기본 체력
  BaseAttack,     // 기본 공격력
  BaseDefense,    // 기본 방어력
  WeakElement,    // 약점 속성
  DropTable[],    // 드롭 소재 테이블
  Scale,          // 레벨 스케일링 배율
}
```

### 8-4. 몬스터 소재 드롭

| 획득 방법 | 소재 등급 |
|----------|----------|
| 일반 사냥 시 박리 | 일반 소재 |
| 부위 파괴 보상 | 희귀 소재 |
| 포획 보상 | 포획 전용 소재 (더 좋음) |
| 퀘스트 클리어 보상 | 보상 소재 |

## 9. 퀘스트 시스템

### 9-1. 퀘스트 타입

| 타입 | 목표 | 시간 제한 |
|------|------|----------|
| 토벌 | 지정 몬스터 처치 | 50분 |
| 포획 | 지정 몬스터 포획 | 50분 |
| 수집 | 아이템 N개 수집 | 30분 |
| 호위 | NPC 보호하며 이동 | - |

- 시간 초과
- 기절 3회 (베이스캠프 귀환 = 기절 1회 소모)

### 9-3. 퀘스트 랭크 구조

```
저랭크 (1★ ~ 4★)   → 스토리 입문, 기본 소재
고랭크 (5★ ~ 7★)   → 고급 소재, 스킬 발동 방어구
마스터랭크 (MR)      → 최고 난이도, 마스터 소재
```

## 11. 진행 시스템 (Progression)

### 11-1. 성장 경로

```
퀘스트 클리어 → 소재 획득
                    ↓
              무기/방어구 제작·강화
                    ↓
              더 높은 랭크 몬스터 도전
```

플레이어 레벨 없음. **장비 수준이 실질적 성장**.

### 11-2. 헌터 랭크 (HR)

퀘스트 클리어마다 경험치 누적 → HR 상승. HR이 높을수록 고랭크 퀘스트 해금.

### 11-3. 스토리 진행

긴급 퀘스트 클리어 = 스토리 분기점. 각 스토리 챕터 클리어 시 새 필드·몬스터·대장간 레시피 해금.

## 14. 개발 우선순위 (Phase)

| Phase | 목표 |
|-------|------|
| **Phase 1** | 한손검 전투 완성, 더미 몬스터 1종, 마을-필드 이동 |
| **Phase 2** | 소재 드롭·대장간·인벤토리, 퀘스트 시스템 기반 |
| **Phase 3** | 몬스터 2~3종 추가, 부위 파괴, 상태이상 |
| **Phase 4** | 무기 타입 2~3종 추가, 스킬 시스템, 랭크 구조 |
| **Phase 5** | 필드 2~3개 추가, 스토리 퀘스트, 밸런스 조정 |
